# 🧮 Modern Calculator

A clean and modern **web-based calculator** built with HTML, designed for quick and simple mathematical calculations.

## ✨ Features

* ➕ Addition
* ➖ Subtraction
* ✖️ Multiplication
* ➗ Division
* 📱 Responsive interface
* 🎨 Modern and clean design
* ⚡ Lightweight and fast

## 🛠️ Technologies

* HTML5
* CSS3
* JavaScript
